## 2024-06-09 - Added Clear Button to QLineEdits
**Learning:** PyQt5's `QLineEdit` has a built-in `setClearButtonEnabled(True)` method that provides a native, pleasant way for users to clear text inputs (like search bars and API keys) without needing to select and delete the text manually.
**Action:** Use this method to easily enhance input usability wherever a `QLineEdit` is used for filtering or entering data that may need to be quickly reset.
