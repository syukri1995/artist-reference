## 2024-05-24 - QLineEdit Clear Buttons
**Learning:** PyQt5's QLineEdit has a built-in `setClearButtonEnabled(True)` method which is a very easy way to add a native clear button to text inputs, improving usability especially for search and filter fields.
**Action:** Use this property for any QLineEdit that acts as a search, filter, or optional input field to quickly clear its contents.
